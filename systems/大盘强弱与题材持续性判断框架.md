# 大盘强弱与题材持续性判断框架

版本：2026-08-11  
用途：用于盘前、盘中、收盘复盘时判断大盘强弱、预判隔日环境、评估题材持续性。  
颜色规则：红色表示强势、盈利、正反馈；绿色表示弱势、亏损、风险暴露。  
性质：个人交易体系训练材料，不构成投资建议。

## 一句话总纲

**当天强弱看真实赚钱效应，隔日强弱看尾盘资金态度，题材持续性看梯队和容量。**

不要只看指数涨跌。A 股很多时候指数红但个股亏钱，或者指数弱但主线抱团很强。大盘强弱的核心，是“资金是否愿意承担风险，赚钱效应是否扩散，亏钱效应是否收敛”。

## 1. 当天大盘强弱评分

每天 10:00、11:30、14:30、收盘各打一次分。总分 70 分以上才算强，50-69 分算中性，50 分以下算弱。

| 维度 | 强势信号 | 弱势信号 | 分值 |
| --- | --- | --- | ---: |
| 指数位置 | 放量站上 5 日/10 日线，分时回踩不破均价 | 破位、跳水、冲高回落 | 15 |
| 成交量 | 放量上涨，量能支持进攻 | 缩量上涨或放量下跌 | 15 |
| 市场广度 | 上涨家数明显多于下跌家数 | 下跌家数占优，指数被少数权重撑住 | 15 |
| 赚钱效应 | 涨停多、炸板少、连板晋级高 | 炸板多、跌停多、大面多 | 20 |
| 主线状态 | 主线清晰，有中军、有前排、有扩散 | 题材一日游，多方向抢资金 | 20 |
| 持仓反馈 | 持仓强于板块，买入后快速浮盈 | 持仓弱于板块，反弹无承接 | 15 |

| 总分 | 市场定义 | 仓位动作 |
| ---: | --- | --- |
| 80-100 | 强势进攻 | 70%-90%，重仓强势核心 |
| 70-79 | 修复偏强 | 60%-75%，做主线中军和前排 |
| 50-69 | 震荡中性 | 30%-50%，只做确认机会 |
| 0-49 | 弱势防守 | 0%-20%，空仓或轻仓 |

## 2. 盘中快速判断

### 9:30-10:00 看开盘定调

- 指数高开高走、成交放大、主线前排快速确认：偏强。
- 指数冲高回落、前排炸板、后排跟不上：偏弱。
- 指数弱但主线核心强：局部抱团，只能做核心。
- 指数强但个股普跌：假强，不能重仓。

### 10:00-11:30 看主线确认

- 强市场会出现“指数稳 + 主线扩散 + 核心不倒”。
- 弱市场会出现“指数反弹 + 题材轮动 + 冲高回落”。
- 如果上午没有主线，下午不要临时强行找主线。

### 13:00-14:30 看资金是否回流

- 午后资金回流主线，核心重新走强：隔日预期改善。
- 午后资金只拉低位杂毛，核心不动：持续性存疑。
- 午后指数跳水、强票补跌：隔日先防守。

### 14:30-15:00 看隔日资金态度

- 尾盘抢筹核心、涨停封单稳定、炸板回封：隔日偏强。
- 尾盘抢跑、核心漏单、前排炸板不回封：隔日偏弱。
- 尾盘拉指数不拉题材：隔日容易分歧。

## 3. 隔日大盘强弱预判

隔日不是预测涨跌点位，而是预判明天适合进攻、试错还是防守。

| 维度 | 隔日偏强 | 隔日偏弱 |
| --- | --- | --- |
| 今日收盘 | 收在日内高位，分时承接强 | 收在日内低位，尾盘跳水 |
| 成交量 | 放量上涨或温和放量修复 | 缩量反弹或放量下跌 |
| 主线核心 | 核心封板稳，中军趋势强 | 核心炸板、补跌、长上影 |
| 连板梯队 | 高标不断板，中位晋级，低位补充 | 高标断板，中位大面，低位无人接 |
| 亏钱效应 | 跌停少，炸板能回封 | 跌停扩散，炸板亏钱严重 |
| 外部扰动 | 夜盘/外围/消息偏正面 | 外围大跌、监管利空、业绩雷 |

| 预判结论 | 次日策略 |
| --- | --- |
| 隔日偏强 | 可保留核心仓，次日只买强更强或分歧转强 |
| 隔日中性 | 降低预期，只做主线核心确认，不开杂票 |
| 隔日偏弱 | 先处理风险，降低仓位，不急着抄底 |
| 隔日分歧 | 等开盘 30 分钟确认，强者留，弱者走 |

## 4. 题材是否有持续性

题材持续性不是看消息有多大，而是看资金是否持续下注。

| 维度 | 有持续性 | 无持续性 |
| --- | --- | --- |
| 高度 | 有 2 板以上高度或 20cm 核心持续走强 | 只有首日冲高，没有高度 |
| 梯队 | 高中低位完整，晋级顺畅 | 断层严重，只有一只独苗 |
| 容量 | 有成交额大的中军承接资金 | 全是小票，容量不足 |
| 扩散 | 从前排扩散到产业链、补涨、ETF/中军 | 只拉少数后排，核心不动 |
| 分歧反馈 | 分歧后回流，炸板能回封 | 分歧后直接退潮 |
| 次日反馈 | 前排有溢价，后排亏钱不严重 | 前排低开，后排大面 |

| 总分 | 题材级别 | 操作 |
| ---: | --- | --- |
| 80-100 | 主线题材 | 可做主仓，围绕核心反复做 |
| 60-79 | 强支线 | 只做前排和中军，不追后排 |
| 40-59 | 轮动题材 | 快进快出，小仓试错 |
| 0-39 | 一日游 | 不参与或只观察 |

## 5. 连板梯队观察

| 梯队 | 看什么 | 含义 |
| --- | --- | --- |
| 高标 | 是否继续晋级，断板后是否温和 | 决定题材高度 |
| 中位 | 是否批量晋级，是否出现大面 | 决定赚钱效应 |
| 低位 | 是否有首板补充，是否扩散到新分支 | 决定持续燃料 |
| 20cm | 是否有创业板/科创弹性核心 | 决定资金风险偏好 |
| 中军 | 是否稳步走趋势，承接是否强 | 决定大资金能否参与 |

强题材通常是“高标打开高度，中位保持梯队，低位不断补充，中军稳住容量”。如果只有高标硬顶、后排大面，题材很容易次日退潮。

## 6. 持仓与市场强弱联动

| 市场状态 | 持仓强弱 | 动作 |
| --- | --- | --- |
| 大盘强 | 持仓强于板块 | 持有或加到计划仓位 |
| 大盘强 | 持仓弱于板块 | 卖弱换强，不恋战 |
| 大盘弱 | 持仓强于板块 | 保留核心，不能加杂票 |
| 大盘弱 | 持仓弱于板块 | 先减仓，必要时退出 |
| 大盘假强 | 持仓不赚钱 | 不重仓，防止指数掩护出货 |

## 8. 最终规则

- 大盘强，重仓强势股。
- 大盘弱，空仓或轻仓。
- 指数假强但个股不赚钱，不重仓。
- 题材没有梯队和容量，不重仓。
- 隔日预判偏弱，第二天先处理风险。
- 只有市场、题材、个股三者共振，才允许进攻。
