# 俞亮亮交易 SOP 总手册

版本：2026-08-11  
定位：把个人交易体系从“原则文档”落成“每天可执行动作”。  
颜色规则：红色表示强势、盈利、正反馈；绿色表示弱势、亏损、风险暴露。  
性质：个人交易训练材料，不构成投资建议。

## 一句话总纲

**大盘强，重仓有持续性的强势核心；大盘弱，空仓或轻仓。每天只按 SOP 做，不按情绪做。**

持续盈利不是每天都盈利，而是让交易长期接近正期望：

> 市场强弱判断 → 题材持续性确认 → 强势核心筛选 → 仓位按胜率放大 → 错了小亏 → 对了让利润跑 → 收盘复盘修正。

## 1. 每日交易流水线

| 环节 | 时间 | 目标 | 产出 |
| --- | --- | --- | --- |
| 盘前计划 | 8:30-9:15 | 判断今天能不能进攻 | 今日市场预判、仓位上限、可交易题材、禁止事项 |
| 集合竞价 | 9:15-9:25 | 验证强弱和风险 | 持仓处理优先级、是否允许新开仓 |
| 开盘确认 | 9:30-10:00 | 只处理最确定的动作 | 强者留、弱者走，不追杂票 |
| 早盘主线 | 10:00-11:30 | 确认主线和核心 | 可交易核心池、仓位是否提高 |
| 午后回流 | 13:00-14:30 | 判断资金是否回主线 | 留核心、减弱票、避免临时切换 |
| 尾盘预判 | 14:30-15:00 | 判断隔日强弱 | 隔日偏强/中性/偏弱/分歧 |
| 收盘复盘 | 15:30 后 | 检查是否按体系执行 | 市场分、题材分、个股分、纪律分 |

## 2. 盘前 SOP

盘前只回答六件事：

1. 昨日市场强弱分数是多少？
2. 今日大盘预判是偏强、中性、偏弱，还是分歧？
3. 今日仓位上限是多少？
4. 今日只允许做哪些题材？
5. 今日只允许买哪些核心票？
6. 今日绝对不做什么？

| 盘前结论 | 仓位上限 | 允许动作 |
| --- | ---: | --- |
| 隔日偏强 + 主线持续 | 70%-90% | 可重仓强势核心 |
| 隔日中性 + 题材分歧 | 30%-50% | 只做核心确认，不追后排 |
| 隔日偏弱 + 亏钱扩散 | 0%-20% | 空仓、轻仓、先处理风险 |
| 大跌后修复观察 | 20%-40% | 观察仓，不急于满仓 |

## 3. 盘中 SOP

### 9:15-9:25 集合竞价

- 持仓大幅低开且弱于板块：准备减仓。
- 主线前排超预期：观察，不直接追。
- 题材前排一字跌停或大幅低开：后排不买，已有后排先卖。
- 指数竞价弱、核心股弱：今天降仓位。

### 9:30-10:00 开盘确认

开盘 30 分钟只问三个问题：

1. 大盘是真的强，还是指数假强？
2. 我持有的是不是今天主线？
3. 我持有的是不是主线核心？

如果三个答案有两个是否定，先降仓位，不新开仓。

### 10:00-11:30 主线确认

- 主线扩散、中军稳、前排封住：允许做核心确认。
- 主线分歧、后排大面、炸板增加：不追，降低预期。
- 没有主线：不强行交易。

### 13:00-14:30 午后回流

- 午后资金回流主线：核心可持有。
- 午后只拉低位杂毛：不追。
- 午后指数跳水、强票补跌：先防守。

### 14:30-15:00 尾盘预判

- 尾盘抢筹核心：隔日偏强。
- 尾盘抢跑、核心漏单：隔日偏弱。
- 尾盘拉指数不拉题材：隔日容易分歧。

## 4. 买入 SOP

任何买入必须先过九问：

1. 今天市场评分是多少？
2. 现在是强市、中性、弱市，还是修复观察？
3. 这笔交易属于哪一种允许模式？
4. 买的是主线核心，还是后排补涨？
5. 它是否强于指数、强于板块、强于同梯队？
6. 如果是追股，题材是否有持续性，明天是否还有人接？
7. 错了在哪里卖？
8. 最大亏损多少钱？
9. 如果明天低开，是否还有现金和心态处理？

回答不清楚，不买。

## 5. 追股 SOP

追股只允许追三类：

| 类型 | 条件 | 仓位 |
| --- | --- | ---: |
| 强市主线核心 | 大盘强、主线持续、核心强于板块 | 8%-15% |
| 分歧回封前排 | 题材有梯队，前排炸板后回封 | 3%-8% |
| 趋势中军突破 | 中军放量突破或缩量回踩转强 | 8%-15% |

追股三条红线：

- 题材没有持续性，不追。
- 不是核心地位，不追。
- 隔日没有承接预期，不重仓追。

## 6. 卖出 SOP

| 触发条件 | 动作 |
| --- | --- |
| 跌破买入理由 | 先减仓，不讲故事 |
| 个股弱于板块 | 反弹减，换强或空仓 |
| 板块核心转弱 | 降低同题材仓位 |
| 题材持续性证伪 | 退出题材后排，只留核心观察 |
| 盈利远离均线 | 分批止盈，至少兑现 1/3 |
| 冲高不封、长上影 | 弹性仓先兑现 |
| 连续两天低于预期 | 退出，不等奇迹 |

## 7. 风控 SOP

| 风控项 | 阈值 | 动作 |
| --- | ---: | --- |
| 单笔风险 | 0.5%-0.8% | 超过不买，或缩小仓位 |
| 日亏损线 | 0.8%-1.0% | 停止新开仓，只允许降风险 |
| 周亏损线 | 2.5%-3.0% | 仓位降到 50%-60% |
| 月回撤线 | 5% | 暂停进攻 3-5 个交易日 |
| 连续两笔计划外亏损 | 2 笔 | 当天停止交易 |

仓位公式：

> 可买金额 = 单笔最大可亏金额 / 预设止损幅度

## 8. 收盘复盘 SOP

收盘只复盘四张分数：

| 分数 | 目的 | 低分动作 |
| --- | --- | --- |
| 市场分 | 判断明天能不能进攻 | 降仓位 |
| 题材分 | 判断题材是否持续 | 不追后排 |
| 个股分 | 判断持仓是否核心 | 卖弱换强 |
| 纪律分 | 判断自己是否失控 | 次日降级 |

纪律分低于 80 分，次日不允许加仓；低于 60 分，次日只处理持仓和观察。

## 9. 周复盘 SOP

每周只统计四件事：

1. 本周赚钱来自哪种模式？
2. 本周亏钱来自哪种模式？
3. 哪些亏损来自不按 SOP？
4. 下周必须删除哪一种动作？

如果一种动作连续三次亏钱，暂停两周；如果一种模式连续三次赚钱，纳入重点模式池。

## 10. 月复盘 SOP

每月只看账户是否更接近正期望：

- 胜率是否提高？
- 盈亏比是否改善？
- 最大回撤是否下降？
- 随手单是否减少？
- 大盘强时是否敢重仓核心？
- 大盘弱时是否能空仓轻仓？

## 11. 持续盈利闭环

持续盈利不是靠预测每一天，而是靠重复下面闭环：

1. 市场强弱给仓位。
2. 题材持续性给方向。
3. 个股强弱给买卖。
4. 风控阈值给底线。
5. 收盘评分给改进。

只有当这五个环节连续执行，账户才有机会从“靠运气波动”变成“靠体系复利”。

## 12. 每日一句执行提醒

**今天不是来证明自己判断对，而是来执行 SOP。市场给机会就做核心，市场不给机会就保现金。**
