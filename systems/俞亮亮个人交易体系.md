# 俞亮亮个人交易体系

版本：2026-08-11  
账户基准：100 万本金目标，当前处于回本修复期  
颜色规则：红色表示盈利、强化、正反馈；绿色表示亏损、回撤、风险暴露。  
性质：个人交易体系与复盘纪律，不构成投资建议。

## 一句话内核

**先判断市场状态，再判断资金路径，只做阻力最小方向里的核心标的；每一笔交易先定义亏损上限，再定义盈利想象。**

这套体系的目标不是每天交易、每天赚钱，而是在可控回撤下持续保留复利能力。看不懂时空仓，做错时立刻处理，做对时让利润保护账户。

## 1. 系统总流程

每天交易只按一个顺序执行：

1. 市场状态：现在是退潮、震荡、修复，还是主升。
2. 仓位上限：市场环境决定最多能买多少，不由情绪决定。
3. 资金路径：钱留在旧主线，还是切到低位新方向。
4. 题材级别：主线、支线、轮动、消息刺激要分清。
5. 个股分层：只做核心、中军、前排、容量锚，不重仓后排。
6. 交易模式：必须归入允许模式，不能临时编理由。
7. 买卖计划：买点、验证点、止损点、止盈点提前写好。
8. 复盘迭代：复盘纪律执行，不只复盘盈亏。

## 2. 市场状态评分

每天盘前、开盘 30 分钟、收盘各打一次分。分数决定仓位上限。

| 维度 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- |
| 指数状态 | 破位/跳水 | 震荡不破位 | 放量站上关键均线 |
| 成交额 | 缩量或无承接 | 平量震荡 | 放量主动进攻 |
| 主线清晰度 | 一日游轮动 | 有方向但分歧 | 主线连续扩散 |
| 赚钱效应 | 炸板/大面多 | 涨跌参半 | 涨停多、反馈强 |
| 持仓强弱 | 弱于板块 | 同步板块 | 强于板块 |

| 总分 | 市场状态 | 仓位上限 | 允许动作 |
| ---: | --- | ---: | --- |
| 0-4 | 退潮/风险期 | 0%-30% | 减仓、止损、观察 |
| 5-6 | 震荡/分歧期 | 40%-60% | 小仓确认，只做核心 |
| 7-8 | 修复/主线清晰 | 70%-80% | 做中军、前排、容量锚 |
| 9-10 | 主升/强赚钱效应 | 85%-90% | 可高仓位，但必须集中核心 |

回本修复期不默认满仓。只有市场评分 9 分以上、持仓强于板块、账户处于盈利顺风期，才允许接近 90%。

## 3. 题材与个股分层

### 题材分层

| 层级 | 特征 | 操作 |
| --- | --- | --- |
| 主线 | 连续 2 天以上扩散，有中军、有前排、有容量 | 可以做主仓 |
| 支线 | 有强票但容量不足，持续性待验证 | 只做弹性仓 |
| 轮动 | 当天强、隔天弱，资金切换快 | 少做或不做 |
| 消息刺激 | 单条消息驱动，未形成梯队 | 只观察，不追后排 |

### 个股分层

| 层级 | 定义 | 仓位 |
| --- | --- | --- |
| 核心锚 | 板块定价中枢，成交额大，决定板块强弱 | 10%-18% |
| 趋势中军 | 行业代表、容量足、趋势清晰 | 8%-15% |
| 前排弹性 | 涨停/20cm/辨识度强 | 3%-8% |
| 后排补涨 | 跟风、弱承接、逻辑不硬 | 不重仓，原则上不买 |

## 4. 四种允许交易模式

| 模式 | 适用条件 | 买点 | 仓位 | 失败处理 |
| --- | --- | --- | ---: | --- |
| 趋势中军 | 市场评分 7+，板块强于指数 | 放量突破或缩量回踩转强 | 8%-15% | 跌破买入日低点或趋势线减 |
| 题材前排 | 题材有梯队，前排封单稳定 | 分歧回封、龙二强跟、20cm 扩散 | 3%-8% | 次日不能转强立刻退 |
| 业绩确认 | 业绩超预期且价格确认 | 公告后放量上涨或强回踩 | 8%-12% | 跌破启动位先减 |
| 恐慌低吸 | 主线核心恐慌释放后止跌 | 放量恐慌后缩量企稳 | 3%-8% | 跌破恐慌日低点退出 |

禁止模式：随手单、补弱票、后排补涨重仓、跌停后讲故事、亏损后马上扳回。

## 5. 仓位与风控

| 项目 | 规则 |
| --- | --- |
| 现金底线 | 正常至少保留 10%-15%；修复期没有现金不新开仓 |
| 单票上限 | 普通 15%-18%；极强核心也不超过 20%-25% |
| 同题材上限 | 正常 35%-40%；主升期最高 50% |
| 单笔风险 | 修复期 0.5%-0.8%；正常期 0.8%-1.0% |
| 日亏损线 | 0.8%-1.0% 停止新开仓 |
| 周亏损线 | 2.5%-3.0% 降仓到 50%-60% |
| 月回撤线 | 5% 暂停进攻 3-5 个交易日 |

仓位公式：

> 可买金额 = 单笔最大可亏金额 / 预设止损幅度

例如账户 83.6 万，单笔最大亏损 0.8% 约 6,700 元，止损 8%，单票可买约 83,750 元，约占账户 10%。

## 6. 买入前检查

买入前必须能回答：

1. 今天市场评分是多少？
2. 这笔交易属于哪一种允许模式？
3. 买的是主线核心，还是后排补涨？
4. 错了在哪里卖？
5. 最大亏损多少钱？
6. 如果明天低开，是否还有现金和心态处理？

回答不清楚，不买。

## 7. 卖出规则

| 情况 | 动作 |
| --- | --- |
| 跌破买入理由 | 先减仓，不讲故事 |
| 个股弱于板块 | 反弹减，换强或空仓 |
| 板块核心转弱 | 降低同题材总仓位 |
| 盈利远离均线 | 分批止盈，至少兑现 1/3 |
| 冲高不封/长上影 | 弹性仓先兑现 |
| 连续两天低于预期 | 退出，不等待奇迹 |

盈利不是卖飞的敌人，回撤才是。浮盈仓要保护，弱票不能幻想。

## 8. 每日 SOP

| 时间 | 任务 |
| --- | --- |
| 盘前 | 看指数、成交、主线、持仓强弱，写下今日仓位上限 |
| 9:15-9:25 | 看竞价强弱，不冲动追高 |
| 9:30-10:00 | 先处理持仓，再考虑新机会 |
| 10:00-11:30 | 确认主线和核心，只做计划内动作 |
| 13:00-14:30 | 处理上午验证后的强弱，不临时切杂票 |
| 14:30-15:00 | 降低不确定仓位，避免尾盘情绪单 |
| 收盘后 | 复盘纪律执行、题材强弱、持仓结构和明日计划 |

## 9. 复盘评分

每天收盘后给自己打分。体系分比盈亏更重要。

| 维度 | 分值 |
| --- | ---: |
| 是否按市场评分控制仓位 | 20 |
| 是否只做允许模式 | 20 |
| 是否买核心、不买后排 | 20 |
| 是否执行止损/止盈 | 20 |
| 是否没有随手单 | 20 |

80 分以上才允许次日正常交易；60-79 分降低仓位；60 分以下次日只允许处理持仓和观察。

## 10. 长期维护规则

- 每周更新一次：新增有效案例、删除无效规则。
- 每月更新一次：统计哪种模式赚钱，哪种模式亏钱。
- 每次大亏后更新：必须写出失控链条和新闸门。
- 每次大赚后更新：确认盈利来自体系，还是来自运气。
- 任何规则如果连续三次无法执行，要么改得更具体，要么删除。

## 最终提醒

账户回本靠的不是一次满仓押中，而是少犯大错、重复正确动作、把盈利留在账户里。交易体系的价值，是在你最想乱来的时候，替你挡一下。
